# 🔗 Chronos Tether | SCP:SL EXILED Plugin

![EXILED Version](https://img.shields.io/badge/EXILED-8.0.0%2B-blue)
![SCP:SL Version](https://img.shields.io/badge/SCP:SL-13.0%2B-red)
![Release](https://img.shields.io/badge/Release-v2.0.1-brightgreen)

**Chronos Tether** is a highly visual, game-breaking custom weapon plugin for SCP: Secret Laboratory servers using the EXILED framework. 
Shoot any player or SCP to attach a space-time anchor, visualized as a glowing, rotating **double-helix energy beam**. The target has 10 seconds to run away. Pressing Reload `[R]` instantly pulls the victim across the map directly to you!

## 🌟 Features (ENG)
* 🌀 **Epic Visuals:** A procedurally generated double-helix particle beam connects the attacker and the victim in real-time.
* ⚡ **Pull Mechanic:** Interrupt your weapon reload to yank your target from anywhere (perfect for pulling enemies out of elevators or into Tesla gates).
* 💬 **Immersive Feedback:** Custom colored hints and UI messages for both the attacker and the victim.
* ⚙️ **Fully English:** All in-game text, hints, and item names are translated to English.
* 🔧 **Stable:** Built on EXILED's CustomWeapon API, no messy role-spawn workarounds.

## 📥 Installation
1. Download the latest `ChronosTether.dll` from the [Releases](../../releases) page.
2. Place the `.dll` file into your server's `EXILED/Plugins/` folder.
3. Restart your server.

## 🎮 Commands
You can give yourself the weapon via Remote Admin (M):
* `givetether` (Alias: `gt`) - Gives the Chronos Tether to the command executor.

## 🇷🇺 Описание на русском

**Chronos Tether (Временной Якорь)** — это фановый плагин для серверов SCP:SL, добавляющий уникальное кастомное оружие. 
Выстрелите в любого игрока или SCP, чтобы прикрепить к нему пространственный якорь. Связь отображается в виде красивой, вращающейся **двойной спирали из светящихся частиц**. У жертвы есть 10 секунд на побег. Нажатие кнопки перезарядки `[R]` мгновенно притянет жертву обратно к вам!

## 🌟 Особенности
* 🌀 **Эпичная анимация:** Процедурно генерируемый луч в виде молекулы ДНК (двойная спираль), который динамически тянется за жертвой.
* ⚡ **Механика притягивания:** Идеально подходит для того, чтобы выдергивать Хаоситов из уезжающих лифтов или затаскивать SCP в Тесла-ворота.
* 💬 **Внутриигровые уведомления:** Яркие кастомные хинты на экране для охотника и его жертвы.
* 🔧 **Стабильность:** Написано с использованием официального API CustomItems.

## 📥 Установка
1. Скачайте последний файл `ChronosTether.dll` на вкладке [Releases](../../releases).
2. Поместите файл в папку `EXILED/Plugins/` на вашем сервере.
3. Перезапустите сервер.

## 🎮 Команды
Выдача предмета через панель администратора (Remote Admin):
* `givetether` (Сокращение: `gt`) - Выдает Временной Якорь.
